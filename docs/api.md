# API 参考

> 说明：以下接口仅为本项目文档演示使用，为模拟接口，不部署后端服务，无法发起真实网络请求，仅用来展示接口文档的编写格式。

## 查询文档列表

- 请求方法：GET
- 请求路径：/api/docs
- 功能：返回本站全部文档条目列表，包含文档编号、文档标题、访问路径、更新时间等基础信息。

### 请求参数
无

### 返回示例
```json
{
  "code": 200,
  "msg": "success",
  "data": {
    "items": [
      {"id": 1, "title": "使用指南", "path": "/guide/", "update_time": "2026-11-03"},
      {"id": 2, "title": "关于本项目", "path": "/about/", "update_time": "2026-11-03"},
      {"id": 3, "title": "API 参考", "path": "/api/", "update_time": "2026-11-03"}
    ]
  }
}
```
