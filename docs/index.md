# 我的技术文档

欢迎访问我的个人文档网站。本网站使用 MkDocs 构建，通过 GitHub Actions 自动部署到 GitHub Pages。

- 作者：LengGuang2678
- 实践主题：静态文档自动部署
- 本次实践体会：通过本次作业，我学习了MkDocs静态文档的搭建流程，理解了GitHub Actions持续部署的工作逻辑，实现修改Markdown文档后自动更新公开网页。在实操过程中，我熟悉了Git完整的提交推送流程，也体会到CI/CD自动化带来的便利：不再需要手动编译、上传网页文件，只需要专注写好文档源码。同时我也遇到了YAML缩进、图片路径、大小写不一致等容易踩坑的细节问题，学会了通过查看Actions运行日志排查部署失败原因，对版本控制、静态站点托管、自动化流水线有了更加具象的认识。这次实践也让我感受到，把文档和自动化部署结合起来，可以很方便地维护一套持续更新、可随时对外分享的在线笔记。
